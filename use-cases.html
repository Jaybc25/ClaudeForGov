How this catalog was made

These examples are written for ClaudeForGov from common public sector work patterns. Some problem areas were informed by the separate JayAI use case inventory, but NVIDIA-specific blueprints, descriptions, product links, and infrastructure recommendations were not carried over. Organization and department tags indicate possible fit, not that every agency has that function or the same authority. Route suggestions are hypotheses to test in discovery.
