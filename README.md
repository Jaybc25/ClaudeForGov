# ClaudeForGov

An independent project exploring how government teams could use Claude to improve services, expand staff capacity, and evaluate costs and measurable outcomes.

## Planned experience

The site will guide a visitor through one connected decision:

1. **Explore a use case.** Define the government workflow, audience, current effort, and desired service outcome.
2. **Choose a Claude route.** Compare Claude Chat, Claude Cowork, Claude Code, and Claude API based on the work to be done.
3. **Estimate cost.** Use route-appropriate assumptions. For API use cases, model input and output tokens, model choice, and cost per million tokens with dated pricing sources.
4. **Estimate value and plan a pilot.** Show editable assumptions for staff capacity, service impact, implementation cost, and realization. Summarize what should be validated before a production decision.

The initial audience is public sector teams, with examples spanning state and local government. The project is intended to become a reviewable working site rather than a static portfolio mockup.

## Current status

The repository is at its initial planning stage. Product requirements, source data, calculations, interface, and deployment have not been implemented yet.

## Independence and limitations

ClaudeForGov is a personal, independent project. It is not an Anthropic product or an official government procurement or security assessment. Estimates will be directional, disclose their assumptions and sources, and distinguish product capabilities from agency-specific deployment requirements.
